# SYNTAX USED:

```
#include <iostream> means include the header specified in the triangle brackets

using namespace std; means that we can use names for objects and variables from the standard library.

C++ compilers ignore blank lines

int func(); is to use a function

After any statement, you need a semi-colon (;)

cout means print the text in the quotation brackets after the insertion operator

<< is the insertion operator

// is the inline comment

/* starts a multi-line comment and */ ends it

C++ is a case-sensitive programming language meaning "cout" and "Cout" is a different command

\n after a statement in quotes in a cout execution makes another line
\n\n makes a blank line and then puts something else after a command
the "endl" manipulator also creates a new line

the escape sequence forces the cursor on the compiler to change position

\n is the escape sequence to go to the next line
\t is the escape sequence to perform a horizontal tab character
\\ is the escape sequence to print a backslash character(\)
\" is the escape sequence to print a double quote character(")
a "return n" is the ending the command with n being an integer of is 0 then there are no errors, if the number is any other that 0 that is the error
you must add the insertion operator before an escape sequence

in a function the code has to be in the curly brackets

you can have as many cout commands in succession inside a function

the "cout" object along with the "<<" operator is used to print text to the compiler
Text must be in Double Quotes ("")
to print numerals, you do not put numerals in Double Quotes
you can also do mathematical operations ( + - * / ^ )
```
